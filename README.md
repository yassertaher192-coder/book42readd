# المكتبة الأدبية الرقمية (النواة)

## التشغيل محليًا
1. `npm install` (يتطلب Node 18+)
2. `cp .env.example .env` ثم ضع قيمة عشوائية طويلة في `SESSION_SECRET` (`openssl rand -hex 32`)
3. إنشاء قاعدة البيانات: تُنشأ تلقائيًا في `data/library.db` عند أول تشغيل.
4. إنشاء حساب المالك (مرة واحدة):
   `ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='كلمة-مرور-طويلة-12+' node create-admin.js`
5. `npm start` ثم افتح `http://localhost:3000` والإدارة في `/admin/login`.

## النشر
- استضافة Node.js (VPS أو Render/Railway مع قرص دائم لمجلدي `data/` و`uploads/`).
- اضبط `NODE_ENV=production` و`SITE_URL` وأضف النطاق عبر سجل DNS (A أو CNAME) وشهادة HTTPS (Caddy أو Nginx + Let's Encrypt).
- خذ نسخًا احتياطية دورية لمجلدي `data/` و`uploads/` واحفظها بعيدًا عن المجلد العام.

## ما هو مُنفَّذ
واجهة عامة RTL داكنة/ذهبية، رفوف فارغة افتراضيًا برسالة قابلة للتعديل، صفحات كتب ديناميكية، بحث، مسودة/نشر/جدولة، رفع غلاف مع فحص المحتوى الفعلي، لوحة مطوّر محمية (صلاحيات من قاعدة البيانات، CSRF، تحديد محاولات الدخول)، سجل عمليات، sitemap وrobots وOpen Graph.

## غير مُنفَّذ بعد
المتجر والدفع وحسابات القراء والمفضلة وقارئ PDF ومكتبة الملفات والوسوم والصور الإضافية وصفحات المؤلف/التواصل/الأسئلة وسياسة الخصوصية، وإدارة الألوان والشعار، والاختبارات الآلية.
